1 · Data

Starts with fictional demonstration stops. Do not upload children's personal data into an unapproved hosted service. This local HTML processes CSV in your browser; map tiles are requested from OpenStreetMap; use fictional data only.

Required headers: id, address, lat, lon, campers. Optional: type (Door to Door / Central Stop), policy (Dedicated / Mixed Allowed), group (linked stop group). One row per physical pickup location. Do not include camper names.

2 · Routing and fleet

The default camp marker is a fictional test destination, not a verified Rolling Hills entrance. Change these coordinates only for approved test locations.

8:50 AM arrival targets a 10-minute buffer before 9:00 AM.

The demo service has no live traffic. Road times are baseline estimates, not operational guarantees. Up to 40 fictional pickup stops per test.

3 · Director route editor

Select a route, then use the editor below the map. Manual changes do not trigger optimization. Locked routes cannot be changed until unlocked. Approval is explicit.

Drafts are stored in downloaded files, not a server. A new Generate action replaces the current draft after confirmation.
